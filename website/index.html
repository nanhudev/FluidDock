关于 DockBot

DockBot 是 nanhudev 开发的免费开源 Windows 桌面助手，采用 MIT 许可证。它将桌面 Dock、应用管理、约 17 KB 的本地意图模型、工作空间与电脑整理放在一起。支持 Windows 10 / 11，需要 .NET Framework 4.8。配置与可选使用记录保存在本机。

DockBot is a free, open-source native Windows dock and local intent assistant. Organize applications, switch workspaces and search files with a lightweight desktop companion.
