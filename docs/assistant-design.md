# 本地助手与回归边界

## 管线

输入 → 否定和范围检查 → 显式规则 / 字符 n-gram 分类 → 软件与网站解析 → 类型化计划 → 预览 → 用户执行。

动作只来自白名单。分类器不能生成程序路径、命令、PowerShell 或卸载指令。路径来自已发现安装入口、用户拖入的文件、用户选择的目录；网站仅允许 HTTP(S)。打开／关闭应用通过已解析的入口执行。关闭只调用匹配 EXE 的 `CloseMainWindow`，不强制终止，不关闭 Explorer、系统组件或 Dock 自身。

19 类：add、remove、move、group、sort、theme、size、search、autohide、startup、widget、tracking、undo、help、unknown、open、close、configure、care。网站作为 add 的受控实体；清理意图只打开待授权面板。

字符 1–3 gram，多项式朴素贝叶斯，规则优先；模型建议要求分数 ≥0.62、第一第二名差值 ≥0.45。分数没有经过真实用户校准。训练数据为 274 条合成短句，测试主要验证产品契约，不能用作泛化准确率报告。

| 只有 moodle | 询问学校或网址 |

| 拖出后按 Esc / 丢失鼠标捕获 | 取消；不删软件 |
| 快捷方式带参数及工作目录 | 解析后保留，不替换为别的扫描结果 |
| 原程序移动 / 同名假文件 | 根据身份修复；身份不符不替换 |
| 清理扫描后文件被修改 | 执行前复核并跳过 |
| 越界路径、相似前缀目录 | 拒绝处理 |

| 安装器、运行库、驱动、许可证管理器 | 不作为一键配置推荐 |

分类包括系统、AI、办公、开发、音乐、游戏、常用网站、其他工具。UU 远程／飞书归办公，Blender／UE 归开发，Cubase／网易云归音乐。用户后续手动改类会保留。

## 清理流程

用户选范围 → 只读扫描 → 逐项未勾选的候选清单 → 勾选 → 二次确认 → 保存本地授权清单 → 重新校验 → 归档或回收 → 记录结果。

用户临时目录仅列出指定后缀、超过七天未访问或修改的文件。大文件需要用户判断内容，排除系统／隐藏文件、链接、系统和应用目录、程序、驱动等。固定磁盘以外不执行清理。每次扫描最多 20 秒、4000 个目录和500个候选；不能穷尽整个电脑。文件没有因为“常见可清理”而自动获准。

Windows 使用记录不是完整运行历史；后台运行和缺少记录均不等于无用。卸载列表的登记大小可能过时；每个应用仍由 Windows 执行卸载确认。本版本没有主动清空回收站、清理注册表或自动删系统缓存的功能。

## 验证说明

`build.ps1 -Test` 当前 106 项契约与回归检查；隔离目录原生 UI smoke 12 项流程。软件匹配测试使用合成入口；不能用来证明特定用户已经安装软件。UI smoke 驱动应用内部流程并截图，不等于真实鼠标拖入、跨屏、高刷新率或所有硬件均已测试。

Hover 使用同一弹簧驱动，稳定后停止 Rendering；Bot 探头沿用同一驱动。图标缓存与稳定原生玻璃窗口避免悬停修改窗口几何。性能分析工具报告 WPF 更新耗时与帧间隔，不代表 GPU 总帧时或所有设备帧率。
