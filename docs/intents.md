# DockBot 指令

应用名称使用本机发现的入口；中英文别名、常见错拼和拼音由软件解析器处理。

| 操作 | 示例 |
| --- | --- |
| 添加 | 添加应用 A；把应用 A 和应用 B 加入 Dock |
| 移除 | 把应用 A 移出 Dock |
| 排序 | 把应用 A 放到应用 B 前面；把应用 A 放到最后 |
| 分类 | 把应用 A 归到开发；把应用 A 和应用 B 放进音乐分组 |
| 智能排序 | 按使用频率排序 |
| 改名 | 把应用 A 改名为常用工具 |
| 隐藏与恢复 | 隐藏应用 A 入口；恢复应用 A 图标 |
| 打开与关闭 | 打开应用 A；关闭应用 A |
| 重启应用 | 重启应用 A；重新启动应用 A |
| 窗口 | 切换到应用 A；唤起应用 A；最小化应用 A；最大化应用 A |
| 安装位置 | 查看应用 A 所在文件夹 |
| 使用统计 | 看看应用 A 的使用统计；查看统计 |
| 搜索 | 搜索应用 A；应用 A 的 exe 在哪里 |
| 网站 | 添加 https://example.com/ |
| 外观 | 换成浅色主题；换成石墨风格；图标小一点；尺寸调到 90% |
| 自动收起 | 开启自动隐藏；一直显示 Dock |
| 自启动 | 开机自动启动；取消开机自启 |
| 小组件 | 显示时钟小组件；隐藏桌面时钟 |
| 统计开关 | 开启使用统计；关闭点击统计 |
| 撤销 | 撤销刚才的操作 |
| 配置 | 一键配置 Dock |
| 整理 | 整理桌面；清理临时文件；清理大文件；清理 C 盘 |

## 工作空间

| 操作 | 示例 |
| --- | --- |
| 管理 | 列出我的工作区；管理工作空间 |
| 保存 | 将当前布局保存为学习工作区 |
| 新建 | 创建论文工作区 |
| 切换 | 我要开始开发了；开始办公；切换到娱乐模式 |
| 返回 | 回到默认布局 |
| 改名 | 把学习工作区改名为课程 |
| 添加入口 | 把应用 A 加入学习工作区 |
| 打开整组 | 打开学习工作区的全部应用 |
| 删除 | 删除论文工作区 |

切换布局保留正在运行的窗口。重启应用采用正常退出，保存提示或后台实例阻止退出时停止重启。

## 电源与系统

| 操作 | 示例 |
| --- | --- |
| 电源面板 | 打开电源菜单 |
| 关机 | 关机；关闭电脑 |
| 重启电脑 | 重启电脑；重新启动电脑 |
| 更新电源 | 更新并关机；更新并重启 |
| 锁屏 | 锁屏；锁定电脑 |
| 睡眠与休眠 | 睡眠；休眠 |
| 注销 | 注销；退出登录 |
| 取消系统待关机任务 | 取消关机；取消重启 |
| 常用文件夹 | 打开下载文件夹；查看文档目录；打开桌面文件夹 |
| 设置 | 打开声音设置；打开显示设置；打开网络设置 |
| 更多设置 | 打开蓝牙设置；打开存储设置；打开电源设置；打开应用设置；打开更新设置 |

电源操作需要确认；更新电源转交 Windows 的更新页面与原生关机面板，可用选项由系统状态决定。

39 类任务由 19 标签、17,311 字节的本地分类模型与显式规则组合解析。未知应用、歧义入口、未支持的时间条件和复合系统操作会要求补充或拆分。

实现依据：[Windows shutdown](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/shutdown)、[Shell.ShutdownWindows](https://learn.microsoft.com/en-us/windows/win32/shell/shell-shutdownwindows)。
